# Category card system

The home grid uses one visual family across all categories. Each card has a calm lavender field, brand purple through the middle, and restrained dark purple depth in the lower right. The dark area stays away from the top-left copy.

## Layout

- Three cards per row.
- Card aspect ratio: 4:5.
- Corner radius: 18 px at the reference viewport.
- Category name and save count are native text in the top left.
- One oversized embossed symbol sits in the lower right and may crop at the card edges.
- A fine purple border and low purple shadow separate the card from the light app background.

## Colour

- Brand purple: `#6D46F2`
- Deep purple: `#241F44`
- Card base: `#F1ECFA`
- Category name: `#241F44`
- Save count: `rgba(65, 35, 61, 0.58)`
- Border: `rgba(109, 70, 242, 0.14)`

## Type

Use Garet for the category name and save count once the licensed mobile font files are available. Keep the category name bold and the count medium. Labels may wrap to two lines; counts stay on one line.

## Artwork rules

- Do not bake copy or save counts into the image.
- Do not introduce category-specific colours.
- Keep the upper-left area quiet for readable copy.
- Match motif size optically across the set rather than using one mechanical scale.
- Use the Other artwork for any new category until a dedicated motif is approved.
