1 · Apple — App Store Connect your hands

  1. Agreements, Tax, and Banking → make sure the Paid Apps agreement is active and banking + tax forms are complete. Nothing sells until this is green, and it can take a day to clear.
  2. Small Business Program — apply at the App Store Small Business Program page while signed in as the account holder. Commission drops from 30% to 15%. Do this first; it is not retroactive.
  3. App → Subscriptions → create a subscription group named Allkept.
  4. In the group, create allkept_monthly: reference name "Allkept monthly", duration 1 month. Under Availability, deselect all countries except United States. Under Subscription Prices, set United States to $2.99. Add the English (US) localisation: display name "Allkept", description "Keep saving, sorting and finding what you save."
  5. Create allkept_yearly the same way: 1 year, United States only, $27.99.
  6. Both products need a review screenshot — I will give you the paywall screenshot once it exists; upload it then. Until then leave them in "Missing Metadata"; it does not block the code.
  7. App Store Connect → Users and Access → Sandbox → Testers → add a sandbox tester with a fresh email you control. Note the email and password: that is the account the simulator will buy with, for free.
  8. In-App Purchase Key (for RevenueCat): Users and Access → Integrations → In-App Purchase → generate a key, download the .p8 once, note the Key ID and Issuer ID. RevenueCat asks for these in step 3.
  9. App Store Server Notifications: leave for RevenueCat to configure — it gives you a URL to paste into App → App Information → App Store Server Notifications (production and sandbox).

2 · Google — Play Console your hands

  1. Monetisation setup → make sure a payments profile is linked to the developer account.
  2. App → Monetise → Products → Subscriptions → create allkept_monthly (name "Allkept monthly"). Add a base plan monthly, auto-renewing, 1 month. Under regional pricing, set United States $2.99 and remove every other country — availability is per base plan. Activate the base plan.
  3. Create allkept_yearly with base plan yearly, 1 year, United States only, $27.99. Activate.
  4. Setup → License testing → add your Google account email as a licence tester so purchases are free and instant on a test device.
  5. For RevenueCat: Google Cloud service account with access to the Play Developer API for this app. RevenueCat's setup page walks through it and asks for the JSON key. Also enable Real-time developer notifications with the Pub/Sub topic RevenueCat gives you.

3 · RevenueCat your hands

  1. Create a project Allkept. Add two apps: Apple App Store (bundle id app.allkept.mobile; paste the In-App Purchase key from Apple step 8, its Key ID and Issuer ID, and the App-Specific Shared Secret from App Store Connect → App Information) and Google Play (package app.allkept.mobile; upload the service-account JSON).
  2. Products → import or add allkept_monthly and allkept_yearly from each store (RevenueCat can fetch them once the store credentials are in).
  3. Entitlements → create allkept and attach all four store products (two per store).
  4. Offerings → the default offering with two packages: Annual → allkept_yearly (both stores), Monthly → allkept_monthly (both stores). Make it current.
  5. Integrations → Webhooks → add a webhook. URL: https://yurbmcqoqyehbpoqplcr.supabase.co/functions/v1/billing-webhook. Enable HMAC signing and copy the signing secret. Environment: both sandbox and production events.
  6. API keys → copy the public SDK keys for the Apple app and the Google app. These are safe to ship in the app. Do not copy the secret API key anywhere.
  7. Pricing: free until $2,500 of monthly tracked revenue, then 1% (their pricing page, read 13 Sep 2026). Nothing to set up.
