The marks — a brief for Claude Design

13 September 2026 · every picture the app draws in one style, so it is designed once. 188 marks in four tiers. The key beside each is the file name and the value the database stores — keep it exactly, and a category somebody already picked keeps its mark when this set replaces the Fluent one.

In plain English. The app needs pictures in five places: the fifteen categories it sorts into; the shelf of marks a person picks from for a category of their own; the three states a save can be in; the app's own ideas — a save, a shelf, a thread, a door — for empty screens and the set-up cards; and, later, one mark per thing a Make produces. Draw the first tier and the app is whole; the rest make it feel finished.

The style — read first

  • One object, set down. A single thing, seen from slightly above, soft 3D shading, the way the reference (Square Go) and Fluent 3D draw theirs. No scene, no ground, no text, no letters, no logos of other apps.
  • Same light on everything. One light source, top-left, on every mark — that is what makes 120 marks read as one set.
  • No baked shadow. The app draws a soft shadow under every mark itself; a shadow in the file would double up.
  • Legible at two sizes. Each mark is drawn at 68pt on the wide cards and at 18pt inside an interest pill. Big simple silhouettes; no thin lines, no small details that vanish at 18pt. Squint test: if the silhouette is not obvious blurred, simplify.
  • Warm, saturated, not neon. They sit on a pale grey card in light mode and a dark grey one in dark mode. Avoid pure black outlines and pure white fills — both vanish on one of the two greys. Mid-tones with highlights survive both.
  • Bodies: silhouettes or none. Where a person is needed (running, dancing, a family), a smooth silhouette in one neutral colour — no skin tones, no faces. The laughing face for Memes is the one face in the set, by design.
  • Two markets in one shelf. India and the US both save here: a diya sits beside a pumpkin, cricket beside American football, biryani beside a burger, a saree beside a dress. Neither should feel like the guest.
  • Nothing brand-shaped. No Instagram, YouTube, TikTok, Apple, Google, Netflix objects — platforms have their own logos and the app draws those separately.

Export and naming

  • PNG, transparent, square, 256 × 256. The object fills about 80% of the canvas, centred, with the same margin on every mark. The app scales down; it never scales up.
  • One file per key, named exactly as the key — lowercase, underscores, no spaces: house_with_garden.png. The file name becomes the database value, so a rename is a migration.
  • Deliver as a folder (or a zip). Drop it anywhere and tell me where; a script lists the folder into the app and checks every key in the tables above is present, so a missing one is caught before it is a blank tile.
  • Dark mode needs no second set. Follow the colour note above and one set works on both greys. If a mark fails on dark, adjust its mid-tones rather than making a dark variant.
  • Sizes to sanity-check in Figma before exporting: 68px (wide card), 56px (card), 30px (picker cell), 18px (interest pill).
