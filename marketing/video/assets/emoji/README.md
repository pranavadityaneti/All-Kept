# Emoji on the cards

Microsoft **Fluent Emoji**, 3D style, MIT licence (https://github.com/microsoft/fluentui-emoji).
144 px PNGs. These are the app's former category marks (`apps/mobile/assets/emoji`, added in
`29d6145`, removed in `2a68d28` when the app moved to Streamline marks). The ad keeps its own
copies so a change in the app can never break a render: the X-style text cards print one inline,
and any card without a photo falls back to one.
