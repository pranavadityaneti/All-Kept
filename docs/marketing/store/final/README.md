## In plain English

- **The first three frames do the selling.** App Store search shows only those three, so each one carries a different reason to download: everything in one place, it sorts itself, and you can find things again.
- **Big, short captions.** Every caption is two short lines in Manrope ExtraBold, the app's own font, set large enough to read on a small search-result thumbnail. Every frame has the same top margin and the same gap between caption and phone.
- **One family of colours.** The backgrounds come from the brand's own gradient (indigo, violet, pink, coral), plus one warm yellow so the set doesn't feel all-purple. Each frame has one solid colour, as in the Luma reference. Frame 3 has dark text because white on yellow is hard to read. Every caption meets the 3:1 contrast standard for large text.
- **A phone that looks real.** It has a metal edge, an even black border, faint side buttons and a soft shadow tinted to match each background. It runs off the bottom edge, like Luma's. The simulator's green "charging" battery is replaced with a plain full battery; that is the phone's status bar, not part of the app.
- **Two frames needed more than a plain phone.** In "Save from any app" the paste box is lifted out of the screen so it reads at a glance. The details screen only fills the top of its phone, so frame 5 shows two phones: the home screen behind and the details sheet in front.
- **Play gets an Android-style phone.** The Play frames use a generic Android phone with an Android status bar, so they don't look like iPhone shots in Google's store. The app screens themselves are unchanged.
- **Tablets are laid out for tablets.** The tablet frames are composed for the 1440 x 2560 canvas, not scaled up from the phone set.
- **Nothing borrowed.** Everything comes from the app's own screens, the Allkept logo and the Manrope font. There are no stock photos, no people, no Apple logo, and no claims beyond what the app does.
